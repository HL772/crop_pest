# 演示脚本（答辩/汇报）

## 1. 演示目标
在 5-8 分钟内完整展示“端云协同识别诊断 + 策略问答 + 批量巡检”。

## 2. 演示准备
1. 启动后端：`python src/web_service.py`
2. 打开浏览器：`http://127.0.0.1:8000`
3. 确认策略服务参数已配置（可选）

## 3. 演示流程

### Step 1：项目定位（30s）
- 介绍项目名称与核心价值：病虫害智能诊断与问答闭环。

### Step 2：模型加载（40s）
- 在页面左侧加载模型。
- 指出系统状态、设备信息、模型参数等监控项。

### Step 3：单图识别（1.5min）
- 上传一张样例图片。
- 展示诊断舞台扫描、Top-5 结果、风险等级和建议动作。

### Step 4：策略查询与追问（1.5min）
- 选择 Top-1 结果，点击查询策略。
- 展示结构化资料（summary/items/sources）。
- 继续提一个追问（如“阴雨条件下如何调整处理节奏”）。

### Step 5：批量识别与导出（1.5min）
- 添加多张图片进入队列。
- 启动批量识别，展示进度与状态。
- 导出 CSV，说明可用于巡检留档。

### Step 6：总结（30s）
- 端侧识别 + 云侧问答 + 会话统计，形成可落地闭环。
- 强调边界：仅辅助决策，需人工复核。

## 4. 备用话术
- 若策略服务不可用：
  - 说明“当前未配置或网络不可达，已自动降级为仅本地识别模式”。
- 若某张图识别不稳定：
  - 说明“模型给出 Top-5 候选，现场应结合症状与环境信息复核”。
