# 已知问题与限制

## 1. 外部服务依赖
- 策略查询与追问依赖 OpenAI 兼容接口。
- 若 API Key、Base URL 未配置或网络不可达，策略功能不可用。

## 2. 训练脚本路径耦合
- `src/train.py`、`src/create_knowledge_base.py` 中存在本地路径配置，迁移环境需手动修改。

## 3. 识别能力边界
- 模型结果为辅助判断，不能替代现场农技诊断和实验室检测。
- 对低质量、模糊、遮挡严重图片，结果稳定性下降。

## 4. 数据域偏移风险
- 若实际田间图像与训练数据域差异大，可能出现误判。
- 建议结合样本回流持续微调模型。

## 5. 安全与配置注意
- 交付到生产环境时，严禁在代码中硬编码 API Key。
- 建议统一使用环境变量和密钥管理方案。

## 6. 平台兼容性
- 已在本地 Windows 环境验证。
- 其他系统需按依赖版本重新验证（尤其是 PyTorch/CUDA 组合）。
