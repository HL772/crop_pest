# 模型与数据说明

## 1. 模型概述
- 主体：`CropDiseaseClassifier`（`src/model.py`）
- 骨干网络：默认 EfficientNet 系列（以训练配置为准）
- 任务类型：多标签病虫害识别
- 输出：Top-5 候选、置信度、风险等级

## 2. 关键文件
- 权重文件：`trained_models/best_model_f1.pth`
- 标签映射：
  - `trained_models/idx_to_label_multilabel.json`
  - `trained_models/label_to_idx_multilabel.json`
- 知识库：`trained_models/knowledge_base.json`
- 中文映射：`trained_models/label_zh_map.json`

## 3. 训练脚本说明
- 文件：`src/train.py`
- 训练配置：`CFG` 字典
- 需在本地修改的关键路径：
  - `data_dir`
  - `save_dir`
  - `resume_from_checkpoint`

## 4. 推理流程
1. 加载模型与标签映射
2. 图片预处理（Resize + Normalize）
3. 模型推理（sigmoid）
4. Top-K 提取（默认 5）
5. 标签可读化与知识库关联
6. 风险分级与诊断摘要生成

## 5. 数据与标签
- 支持融合多类病害与虫害标签
- 标签来源以映射文件与知识库为准
- 识别结果建议结合田间实际症状复核

## 6. 指标说明
- 训练过程关注 `F1` 与 `Accuracy`
- 生产端主要展示候选置信度、风险等级与解释文本

## 7. 适用边界
- 适用于叶片/果面等可见病虫害图像初筛
- 不适用于替代实验室检测与法规级结论
