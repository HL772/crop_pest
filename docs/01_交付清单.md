# 交付清单

## 1. 项目基本信息
- 项目名称：穹农智核：端云协同的多源融合病虫害诊断反馈与智能问答平台
- 英文名称：AgriOmniCore
- 交付日期：2026-04-09
- 交付形态：源码 + 模型文件 + 示例数据 + 文档

## 2. 交付目录（必交）
- `src/`：后端服务、模型加载、训练脚本、桌面 GUI
- `web/`：Web 前端页面与交互逻辑
- `trained_models/`：模型权重与标签/知识库映射
- `sample_images/`：演示样本图片
- `readme.md`：项目说明（中文）
- `docs/`：交付与验收文档

## 4. 启动验收项
1. 启动命令：`python src/web_service.py`
2. 访问地址：`http://127.0.0.1:8000`
3. 核心功能：
   - 模型加载
   - 单图识别（Top-5）
   - 策略查询与追问
   - 批量识别与 CSV 导出

## 5. 验收输出（建议提交）
- Web 主界面截图
- 单图识别结果截图
- 策略问答截图
- 批量识别结果与导出 CSV 截图

## 6. 交付说明
- 若运行环境未配置 OpenAI 兼容服务参数，策略查询功能会不可用，但不影响本地识别功能。
- 识别结果为辅助判断，不替代农技现场诊断或实验室检测。
