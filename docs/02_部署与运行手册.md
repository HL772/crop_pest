# 部署与运行手册

## 1. 环境要求
- 操作系统：Windows / Linux / macOS（推荐 Windows 10+ 或 Ubuntu 20.04+）
- Python：3.10 及以上
- 可选硬件：NVIDIA GPU（用于加速推理/训练）

## 2. 安装依赖
建议先创建虚拟环境后安装：

```bash
pip install fastapi uvicorn torch torchvision timm pillow numpy pandas matplotlib seaborn scikit-learn tqdm pyqt5
```

## 3. 目录约定
- 模型目录：`trained_models/`
- 示例图片目录：`sample_images/`
- 前端静态资源目录：`web/`

## 4. 环境变量配置（策略服务）
按需配置以下变量（PowerShell 示例）：

```powershell
$env:OPENAI_COMPAT_API_KEY="你的Key"
$env:OPENAI_COMPAT_BASE_URL="https://你的兼容接口/v1"
$env:OPENAI_COMPAT_MODEL="deepseek-chat"
```

## 5. 启动方式

### 5.1 Web 版（推荐演示）
```bash
python src/web_service.py
```

浏览器访问：`http://127.0.0.1:8000`

### 5.2 桌面版 GUI（可选）
```bash
python src/gui_app.py
```

## 6. 健康检查
- 接口：`GET /api/health`
- 成功标志：返回 `ok=true`，并包含 `available_models`、`current_model` 字段

## 7. 常见问题
- 无法加载模型：检查 `trained_models/*.pth` 是否存在，且标签映射文件齐全
- 无法调用策略服务：检查 API Key、Base URL、网络连通性
- 图片无法识别：确认为 `jpg/jpeg/png` 且文件非空

## 8. 关闭服务
- 控制台按 `Ctrl + C` 停止后端服务
